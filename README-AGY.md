# Antigravity Starter Kit for FocusFlow

Generated by the `agy` Claude skill on 2026-07-18, from your `project_plan.md`.

## What's in here
- `AGENTS.md` — project context + the five-persona agent team (PM, Frontend, Backend, QA,
  DevOps). Drop at your workspace root; read by Antigravity (and Codex/Cursor by convention).
- `.agents/rules/` — workspace rules: `coding-standards.md`,
  `nextjs-frontend-conventions.md`, `gemini-supabase-backend-conventions.md`.
- `.agents/skills/` — reusable capabilities: `add-api-route`, `gemini-golden-set`,
  `supabase-migration`, `pwa-audit`.
- `.agents/workflows/` — slash-command procedures: `/ship-phase`, `/verify-dod`, `/deploy`.
- `task.md` / `implementation_plan.md` — starter Artifacts seeding your first session, built
  from the 8 phases (each with its Definition of Done).

Keep your `project_plan.md` alongside these — it's the authoritative spec the files point back to.

## How to use
1. Unzip this into your empty project folder (or `git init` it first).
2. Open the folder in Antigravity.
3. Paste the kickoff prompt (given to you in chat) into the Agent Manager.
4. Use Planning mode for the first session so it generates real Artifacts from
   `implementation_plan.md` before writing any code.

## Note
Everything is scoped to Full V1 (Phases 0–8), so Web Push reminders (Phase 5) are a
first-class milestone. Human-in-the-loop steps (🧑) — account/API-key creation, mic
permission, real-device install, and recording the golden-set audio — are flagged inline;
the agents will pause and ask when they reach one.
